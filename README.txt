# Cyber Awareness Campaign — Flask Final UI

A web-based Cyber Awareness project developed to promote cyber safety, spread awareness about online scams, and provide useful cybercrime reporting and support resources.

## Project Overview

This academic project aims to help users understand common cyber threats and access cyber safety information through a simple web application. It combines educational resources, cyber scam reporting, emergency helpline information, government resources, and feedback functionality.

## Features

- **Cyber Safety Awareness:** Educational information about online safety and cybercrime prevention.
- **Report Cyber Scam:** A form for submitting details about suspected online scams.
- **Emergency & Helpline:** Information about emergency support and cybercrime helplines.
- **Government Resources:** Useful cybercrime-related resources.
- **Feedback & Survey:** Functionality for collecting user feedback.
- **Admin Dashboard:** Administrative pages for managing and reviewing project information.
- **SQLite Database:** Database integration for storing application data.

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Backend:** Python, Flask
- **Database:** SQLite

## How to Run the Project Locally

1. Download or clone this repository.
2. Open the project folder in VS Code or a terminal.
3. Install the required dependencies:

   ```bash
   pip install flask werkzeug
   ```

4. Run the application:

   ```bash
   python app.py
   ```

5. Open the following address in your browser:

   `http://127.0.0.1:5000`

**Note:** The instructions above assume that `app.py` is present in the project folder and that Flask and Werkzeug are the required dependencies. Additional packages may be needed depending on the code.
